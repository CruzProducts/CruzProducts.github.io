# Carter Cruz — Music Portfolio

## Files
- `index.html` — home page
- `about.html` — biography and musical background
- `music.html` — audio portfolio
- `gallery.html` — performance photos and portraits
- `commissions.html` — composition commissions and contact
- `styles.css` — shared styling used by every page
- `audio/` — put your MP3 files here
- `images/` — put gallery images here

## Publish on GitHub Pages
1. Upload all HTML files and `styles.css` to the same repository directory as your existing `index.html`.
2. Create `audio/` and upload your MP3s there. Keep the filenames referenced in `music.html` exactly the same as the actual filenames in GitHub.
3. Create `images/` and upload your pictures. The gallery template looks for `performing.jpg`, `portrait.jpg`, and `marimba.jpg`; change those paths in `gallery.html` if your filenames differ.
4. Commit changes. GitHub Pages will publish the pages using the same repository settings as your existing site.

Note: This package retains the design from the uploaded portfolio and changes navigation to separate pages. Review the commission/contact details and audio file paths before publishing.
